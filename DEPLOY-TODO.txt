Pre-deploy (local laptop)
-------------------------
[ ] Confirm secrets exist locally (gitignored, not committed):
      ls -l logger/search-app/API_keys.json
      ls -l logger/search-app/service_account.json

[ ] (Optional) Local Docker smoke test (Vertex-only):
      cd logger
      docker compose down --remove-orphans
      docker compose up --build
      Open http://localhost:7001

[ ] Commit + push deployment-test (no auto-deploy fires; branch state only):
      git status
      git add -A
      git commit -m "deploy: ..."
      git push origin deployment-test


First server bring-up (one-time)
--------------------------------
[ ] Connect to USI VPN.
[ ] One-time SSH key setup (so deploy.sh runs without password prompts):
      [ -f ~/.ssh/id_ed25519.pub ] || ssh-keygen -t ed25519 -N "" -f ~/.ssh/id_ed25519
      ssh-copy-id -i ~/.ssh/id_ed25519.pub rotam@solar.usilu.net
      ssh -o BatchMode=yes rotam@solar.usilu.net 'echo ok'
[ ] First deploy run from laptop:
      ./scripts/deploy.sh
[ ] Smoke test from inside the server:
      ssh rotam@solar.usilu.net 'curl -I http://127.0.0.1:7001/'
[ ] Smoke test from your laptop (still on VPN):
      curl -I http://solar.usilu.net:7001/

HTTPS / public access - pending USI input
-----------------------------------------
solar.usilu.net is internal-only. To run a study where participants connect
from outside USI's network we need ONE of:

  A. USI publishes the app via a perimeter proxy (a public hostname like
     `<study>.usi.ch` that proxies to solar.usilu.net:7001 with a real cert).
  B. The study is run with participants on USI VPN or campus only.
  C. Self-signed or USI-internal-CA cert + plain HTTP-or-HTTPS on 7001.

[ ] Decide A / B / C with Monica before any participant data collection.
